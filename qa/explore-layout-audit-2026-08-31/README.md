# Explore 排版稽核（2026-08-31）

## 問題判定

- 桌面版同時顯示側欄與頁首 Logo，造成品牌識別重複。
- 位置／範圍按鈕在 926px 視窗固定為 220px，視覺比重過高。
- 推薦卡與圖片的 DOM 尺寸原本一致；差異感來自桌面版只露出下一張卡的一部分。
- 結果列表卡片只有最小高度，內容量不同時可能造成同列卡片高度不齊。

## 修正規格

- `>= 920px`：保留側欄 Logo，隱藏頁首 Logo，但保留其網格欄位以維持位置摘要置中。
- `>= 720px`：位置／範圍按鈕改為 `clamp(176px, 20vw, 196px)`。
- `920–1099px`：推薦輪播一次完整顯示一張卡，不再露出被裁切的下一張。
- `>= 1100px`：一次完整顯示兩張等寬卡片。
- 推薦卡統一使用等高 Grid／Flex 結構，CTA 固定落在卡片底部。
- 推薦圖片維持 16:9、`object-fit: cover` 與滿寬顯示。
- 篩選結果卡片與連結容器補上 100% 高度，維持同列一致。
