## 本批範圍

保留既有 Vue 介面、背景與毛玻璃導覽。先修正可獨立驗證的活動建立、日期篩選及日曆問題；未改動雲端資料、RLS、RPC、Edge Functions，也未部署或執行 Git commit／push。

專案擁有者確認 Supabase `houban-web-app` 的活動、報名都是測試資料。本批仍全部保留，這項確認不作為刪除資料的依據。

## 已修正

1. 地點選擇完整傳遞 Place ID、名稱、地址、行政區與座標；同名但不同地址不借用本地公園座標，未知座標不再填入台北預設值。
2. 自訂集合地點會寫入建立活動的 `park.meeting`，不改動共用公園種子資料。
3. 新建活動驗證日期、未來開始時間、結束時間、地點、集合處與 3–50 人整數名額。只支援當日活動，不再把錯誤時間自動跳到隔天。
4. 送出時重新檢查目前時間；即使表單已開啟很久，也會顯示新的時間錯誤。
5. 建立流程等待 Supabase 回傳成功，才加入前端清單並導向活動管理；儲存中鎖定表單與按鈕，失敗保留表單及重試入口。
6. 同一次草稿重試沿用 ID，以 `ignoreDuplicates` 避免第二次覆寫已扣減的名額；遇重複 ID 會讀回雲端既有活動確認結果。
7. 今日／明天／本週篩選使用 `isoDate` 與台北時區，不再信任持久化的 `today` 標記。「本週」為今天到本週日。今日推薦仍獨立於下方窄篩選。
8. 指定搜尋範圍時，沒有座標／距離的活動不當作 0 公里。
9. 日曆時間解析修正跨中午與上午／下午；舊資料跨午夜可解析，缺少／無效日期會顯示錯誤而不是生成錯誤日曆。
10. 表單錯誤摘要可聚焦，附欄位連結與行內錯誤；連結將欄位置中捲入畫面。輸入欄位附可讀名稱及錯誤描述關聯。

## 雲端唯讀檢查與上線阻擋項目

已確認正確的 `houban-web-app` 測試專案，唯讀檢查了資料表政策、RPC 定義與 Edge Functions 清單：

- `events`、`registrations`、`favorites` 有允許 public 存取／寫入的寬鬆政策；不能靠前端按鈕或 LIFF profile 阻止越權。
- `register_event_atomic`、`cancel_event_atomic`、`check_in_participant` 接受前端傳入身分，缺少可信任呼叫者／活動主辦人驗證。
- 報名 RPC 的重複報名路徑仍會重複扣名額；活動取消／結束狀態的伺服器端報名限制須一併補齊。
- 本次檢查的 Edge Functions 清單為空；尚未建立可供 RLS 信任的 LINE 身分驗證邊界。

以上問題**未於本批修正**。表單驗證與 organizer ID 傳遞不是安全控制，不應開放真實使用者或真實個資。
